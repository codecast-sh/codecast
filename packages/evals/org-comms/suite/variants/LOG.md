Your team has a shared log. An entry that you put on it reaches every other agent at the start of the next round. Each agent reads only the entries that are new to it. Read the new entries before you act.

An entry is one of three kinds. A fact is a finding that a teammate can use, with its evidence. A fail is an approach that did not work, with the reason, so that nobody tries it again. An interface is a contract that the work of another agent depends on. For example, name a file that you will change and how, before anyone builds on it.

Share an entry when someone on the team may need it. Leave out progress, plans and findings that matter only to you. Keep messages for what must change the next action of one agent now.
