
## Messaging

Session-to-session messages (cast send). Use `cast send <session> "…"` when it changes the recipient's next action, answers a question, prevents a conflict, or delivers finished work. Each send starts a new turn. Keep routine progress in your own session or task; report one verified result, with earlier messages for blockers or material changes. Incoming messages need no acknowledgment. For releases, name one owner and the handoff notification needed.

Run `cast guide messaging` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
