
## Messaging

Session-to-session messages (cast send). Adds `cast send <session> "…"` so your sessions can message each other directly. The text lands as a new turn in the target session, attributed to the sender, and renders as a card in the dashboard showing who sent it.

Run `cast guide messaging` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
