
## Team chat

Post to and read team channels (cast chat). Adds `cast chat` so agents can talk where the team talks: post progress to a channel (a release channel agents report into is one command), read and search the history, and answer when someone @mentions the team's anchor in a thread. Sends from a managed session are stamped as agent-written, so they can never wake another person's machine.

Run `cast guide chat` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
