
## Publishing pages

Shareable published pages (cast publish). Adds `cast publish <file.html>` so agents can publish HTML deliverables — reports, dashboards, mockups — to a stable codecast.sh/a/<id> URL you can open and share. A page URL on its own line in a reply embeds the live page in the conversation. Re-publishing the same file keeps the same link; links are unlisted but viewable by anyone who has them.

Run `cast guide publish` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
