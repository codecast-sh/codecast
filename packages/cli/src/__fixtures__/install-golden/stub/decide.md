
## Asking for a decision

Hand your human one well-formed decision (cast decide). Adds `cast decide` so an agent that hits a real fork — a tradeoff, an irreversible step, a judgment call — posts ONE explicit question with options and enough context to answer without opening the session. Decisions land in the web decision queue, where you clear the stack one at a time with the keyboard; the chosen option arrives back in the asking session as a normal message.

Run `cast guide decide` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
