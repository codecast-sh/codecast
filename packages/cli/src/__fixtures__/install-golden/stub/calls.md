
## Calls

Read transcribed team calls (cast calls). Adds `cast calls` and `cast call <id>` so agents can read the team's huddles: the speaker-attributed transcript, the auto-generated summary and the action items. Nothing joins a call — this is read access to what was said, so a task that says "as discussed on the call" can be traced to the exact line.

Run `cast guide calls` for the commands and flags. The guide ships inside the binary you run, so it always matches the `cast` that will execute them.
