# Weekly lessons for {{project.name}}

The corrections people made to agents working on {{project.ref}} this week are
the project's cheapest evidence of what its instructions fail to say. Run the
cast-lessons skill over the last 7 days, scoped to this project's sessions,
from {{project.dir}} so the profile's project and principles apply (its
instructions say how to search, cluster, match against the principles and file
each cluster).

Every cluster that needs a change goes through the signal door as a lesson
signal into {{project.ref}}, under a fingerprint that names the rule, so a
repeat next week counts toward the same cause instead of opening another. Run
it in its proposing mode: the table and the signals are the deliverable, and
the instruction lines, decisions and principles it suggests are proposals for a
person, not edits you make.

Record in the line ledger how many corrections you read, the clusters, and the
signal and cause each reached. A week with no corrections is a result too:
record it, and say whether the search could see this project's sessions at
all, because an empty week and a blind search look the same.
