Session titles repeat the first message instead of naming the work

Serves Inbox scan time under 20 secondsin-12.m2

A title that repeats the opener makes every row in the inbox look the same, so people open sessions to find out what they are

What is wrong

Session titles copy the first message, so the inbox fills with rows like "hey can you look at" and people open each one to learn what it is.

What this changes

The title prompt now names the work in a short imperative phrase, ignoring greetings and pasted errors.
