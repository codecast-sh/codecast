# Local-First Sync — Adversarial Test Matrix

**Campaign:** exhaustive adversarial verification of the v2 local-first sync layer (pl-205, task ct-40155).
**Scope:** `packages/web/store/local-first/*`, `packages/web/hooks/{useLocalView,useConversationComments,useSyncBuckets}.ts`, Convex view/command substrate. The fenced execution rail is out of scope.
**Method:** every row gets (1) a steelman for why the issue exists, (2) a conclusive experiment, (3) a verdict. `FOUND → FIXED <commit>` or `ABSENT: <test + hand-review note>`. No row closes without a verdict.

Verdict key: **PENDING** (not yet run) · **FOUND** (reproduced) · **FIXED(commit)** · **ABSENT** (test passed + hand review) · **N/A** (unreachable in current rollout stage; noted for the step that makes it reachable).

## Fix decisions taken (flagged for owner review before push)

1. **SRV-01/SRV-02 family — the view revision covers the view's own table writes, not the full query result.** Decision taken: (c) + server-side advances. Client: at equal comparable coverage, granted→granted content converges to the latest **fenced** delivery (the writer + source-sequence fences already prove it is the newest payload this store has observed); "moved backwards", revision-order-integrity, and access-changes-at-equal-coverage rejections are unchanged. Server: every access-changing conversation mutation advances the comments head (guard-test-pinned). Deliberately **weakened**: the "equal revision carried divergent content" tripwire — it fired on legitimate join drift (user rename) and froze views; shadow digests + telemetry remain the divergence detectors. Residual: access regained purely via team-membership re-add regrants at an unchanged revision and stays cleared until the next head advance (narrow, self-healing, security-conservative).
2. **TAB-01 — writer handoff.** Implemented in `LocalViewSession.deliver`: one re-open + re-apply when a superseded delivery is strictly newer than the durable view (or is an access transition). Equal coverage never re-claims, so two live tabs cannot ping-pong the writer.
